History of R3S Games and its predecessors

MMORG

  • Circa 2023: SpruceGuy and Rováne make an idea for "MRG", a website featuring three games: Monka-Stick (an animation-based game), Lucky (a game of chance), and MINT (a block-based game similar to Minecraft), which was never created.
  • Circa 2023: MRG is first created on Replit, with only a home page.
  • Circa 2023: Another developer joined, and Lucky and Monka-Stick were released. The website is renamed to "MMRG".
  • Circa 2023: Redunz joined the project, and it was renamed to "MMORG".
  • June 2024: A clicker and farming game, Cooki, was released to MMORG. More details about Cooki can be seen here.
  • Late 2024: Due to problems with Replit, updates stopped coming to MMORG.

Denial Game Era

  • 2025: A new hosting service was found, and the original MMORG website was migrated there.
  • 2/6/2025: A clicker game, Denial, was released.
  • 5/16/2025: The last update to Cooki was released.
  • 11/10/2025: A new game, Countrysim, was released.

Early GitHub Era

  • November 2025: The project was moved to GitHub Pages, with only CountrySim. The repository still exists here, under SpruceGuy's account.
  • 11/22/2025: Blocks was released. This edition is now called "Blocks Legacy".
  • 12/2/2025: Blocks was released. This edition had better maps and graphics, plus a larger grid size.
  • 2/8/2026 to 4/2/2026: Due to burn-out, Block stopped receiving updates.
  • 5/10/2026: The basic structure of EcoSim was created. The game is currently on hiatus, but may be revisited in Winter 2027.
  • 6/14/2026: The website was renamed to "SpruceGames", the link structure was improved, and old MMORG and Denial games were ported to the GitHub Pages site.
  • 6/15/2026: A game from the Denial era, NGBE, was ported to Github Pages and improvement started.
  • 8/2/2026: Cloud saves were added to NGBE.
  • 8/27/2026: NGBE Deluxe was released.
  • 8/27/2026: EcoSim was revisited.
  • 8/29/2026: EcoSim had a few features added, but was abandoned again.
  • 8/29/2026: Improvements were made to CountrySim. The new game, CountrySim Deluxe, was created.
  • 9/3/2026: CountrySim Deluxe was released. Development of Ferbingo, a tool to learn SpruceGuy's con-lang, began.
  • 9/26/2026: Development of the Koia series began, alongside improvements to Ferbingo.
  • 11/8/2026: The first Koia game with actual mechanics, Koia Aftos, was released.

If it is two bytes (4 hex digits) long, it is a special code.
- 0000 - Empty
- 0001 - Placeholder scheme 
- 0002 - Placeholder scene
- 0003 - Default scheme
- 0004 - Simple extending line
- 0005 - Scheme compressor returns this if there is an error
- 0006 - Scene compressor returns this if there is an error
Example scheme:
{
    "name": "Expander",
    "parts": [
        {
            "id": 0, (hex to decimal)
            "render": {
                "type": "area",
                "size": [1, 1],
                "color": "#000000",
                "expandTo":  "18302628889895108608" (hex to decimal, a 3x3 block of 0x00s)
                "expansionOffset": [-1, -1] (center the 3x3 block on the original 1x1 block)
            }

        }
    ],
    "base": 0 (hex to decimal, 0x00)
}
0xff merges the two nearest bytes
0xfb ends the prop declaration
0xfd means "defined as"
0xfc means "expands to"
0xfe means a line break in expansion, or a comma in an array
